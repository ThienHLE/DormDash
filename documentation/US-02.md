# US-02: Create a Delivery Request

Source: [`deliveries.js`](../api/endpoints/deliveries.js).

The requester provides an item, pickup/drop-off names, and tip. The endpoint creates an open delivery for couriers to discover.

### POST `/api/v1/deliveries/createDeliveryRequest`

**Access:** No login middleware in this handler. `requesterId` comes from the body; it is not derived from or compared with the session.

**JSON body:**

```json
{
  "requesterId": "507f1f77bcf86cd799439011",
  "item": "Coffee",
  "instructions": "No sugar",
  "pickupLocation": "Student Center",
  "deliveryLocation": "Library Entrance",
  "tip": 300
}
```

All fields except `instructions` are required. The requester ID must be a valid ObjectId, and `tip` must be a non-negative integer in **cents** (300 means $3.00). Missing instructions default to an empty string.

The backend saves the document in `deliveries`, adding `_id`, `courierId: null`, `status: "open"`, `createdAt`, and `updatedAt`.

**Success — 201:**

```js
{
  statusCode: 201,
  statusMessage: "Delivery request created successfully.",
  content: {
    _id, requesterId, item, instructions,
    pickupLocation, deliveryLocation, tip,
    courierId: null,
    status: "open",
    createdAt, updatedAt
  }
}
```

ObjectIds serialize as strings and timestamps as ISO strings. The frontend should obtain exact location names from `/api/v1/locations/list`; creation currently does not verify those names against the collection or confirm that the requester account exists.

| HTTP status | Meaning |
| --- | --- |
| 400 | Missing required fields, invalid requester ID, or invalid tip. |
| 500 | Database insertion failed. |

Handled errors return `{ statusCode, statusMessage, content: {} }`. Send a JSON object: body destructuring happens before the handler's database error catch, so a missing body is not guaranteed this JSON error format.

After creation, the delivery appears in [available requests](US-03,US-04,US-08.md). Pickup, status history, and handoff are documented in [US-05/US-06](US-05,US-06.md).
